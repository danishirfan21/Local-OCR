# Local Lens v0.4.0 — first self-contained offline portable release candidate

*Release notes and draft GitHub Release text. This document is prepared
ahead of publication — see the note at the bottom for what's still
pending.*

## One-sentence summary

A self-contained Windows portable build of Local Lens: press a shortcut,
select anything on your screen, and get real, copyable text back — Fast
OCR runs fully offline with no installer and no separate Python setup.

## Highlights

- **Fully offline Fast OCR.** The three EasyOCR model files (English,
  Urdu/Arabic script, and the CRAFT text-detector) are bundled directly
  into the portable build — no `~/.EasyOCR` cache, no model download, no
  network connection required to use Fast OCR.
- **Global capture shortcut** (`Ctrl+Shift+Space`, changeable): dims the
  screen, drag a box, get text back in a popup with a Copy button.
- **English + Urdu**, including mixed-language lines.
- **Optional Deep Analyze**: opt-in, per-capture, BYOK access to Google's
  Gemini API for complex layouts and documents — never auto-triggered,
  shows a privacy disclosure first.
- **System tray app**: Capture / Open Local Lens / Settings / Quit, plus
  optional "Start with Windows" and auto-copy.
- **No installer** — download the ZIP, extract, run the exe.

### Install

1. Download and extract the ZIP anywhere.
2. Run `LocalLens.exe`.
3. Wait a few seconds for "Fast OCR ready" in the tray tooltip / main
   window.
4. Press `Ctrl+Shift+Space`, drag a selection box, get your text.

Windows SmartScreen may warn that this is from an "Unknown publisher" —
the executable isn't code-signed (a paid certificate is required for
that). This is expected for an unsigned indie build; verify the SHA-256
above if you want to confirm the download wasn't tampered with.

## Privacy

Fast OCR never leaves your machine — no image, no extracted text, no
usage data is sent anywhere, and this is enforced by an automated test in
the source repo. Deep Analyze is the one exception: it's fully opt-in,
requires your own Gemini API key, and shows a disclosure before the first
send each session.

## Known limitations

- Windows x64 only.
- English and Urdu only for Fast OCR today.
- Fast OCR is OCR, not a document-understanding model — complex layouts
  and dense tables are where Deep Analyze (Gemini) does measurably
  better.
- Large download (~565 MB) because it bundles a full offline model set.
- Unsigned executable (SmartScreen warning expected).
- Multi-monitor setups are structurally supported but less heavily
  live-tested than single-monitor.
- No installer, auto-update, or uninstaller beyond deleting the folder.

## What changed since the last release candidate (V6.8 → V6.9)

Two real defects were found during release QA and fixed in this build:

- `THIRD_PARTY_NOTICES.txt` (EasyOCR/CRAFT-pytorch attribution) is now
  actually included in the ZIP — it existed in source before but never
  made it into the packaged build.
- Both application windows now show the correct branded icon in their
  title bar (previously a generic default; the taskbar/Explorer icon was
  always correct).

See `docs/V6_9_RC_QA.md` for the full QA record.
