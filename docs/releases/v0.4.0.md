# Local Lens v0.4.0

*Release notes for the GitHub Release. Also lives in the repository at
`docs/releases/v0.4.0.md` for reference.*

## What is Local Lens?

Local Lens is a Windows desktop utility that lets you press a shortcut,
select anything on your screen, and turn it into usable text. This
release is a self-contained portable build — Fast OCR runs fully offline,
with no installer and no separate Python setup required.

## Highlights

- **Global `Ctrl+Shift+Space` capture shortcut** (changeable in Settings)
- **Region selection** — dim-and-drag a box around anything on screen
- **Local, offline OCR** — Fast mode never sends anything over the network
- **Bundled OCR models** — the model weights ship inside the portable
  build, no separate download or `~/.EasyOCR` cache needed
- **English + Urdu**, including mixed-script lines
- **Compact result popup** with a loading state, positioned near your
  selection
- **Copy / Auto-copy** — manual Copy button, or opt in to auto-copy every
  Fast result
- **Optional Gemini Deep Analyze** — opt-in, per-capture, bring-your-own
  API key, for complex layouts and documents; shows a privacy disclosure
  first and is never auto-triggered
- **System tray utility** — Capture / Open Local Lens / Settings / Quit,
  plus optional "Start with Windows"
- **Portable Windows build** — no installer, download the ZIP and run
  the exe

### Install

1. Download the portable ZIP
2. Extract it
3. Run `LocalLens.exe`
4. Wait for Fast OCR to become Ready
5. Press `Ctrl+Shift+Space`

Then drag a selection box around anything on your screen — a result popup
with a Copy button appears in a couple of seconds.

Windows SmartScreen may warn that this is from an "Unknown publisher" —
the executable isn't code-signed (a paid certificate is required for
that). This is expected for an unsigned indie build; verify the SHA-256
above if you want to confirm the download wasn't tampered with.

## Requirements

- Windows 10 or 11, x64
- ~1.1 GB free disk space once extracted

## Privacy

**Fast OCR**: runs locally, does not upload captures, works offline.

**Deep Analyze**: optional, explicit, sends the selected image to Gemini
(your own API key) — never triggered without a click, and shows a
disclosure first.

## Known limitations

- Initial OCR warm-up takes ~10 seconds on first launch.
- Unsigned executable may trigger a Windows SmartScreen warning.
- Windows x64 only for this release.
- Fast table extraction is limited compared with Deep Analyze.
- Deep Analyze requires Gemini configuration (your own API key) to use.
- English and Urdu only for Fast OCR today.
- Large download (~565 MB) because it bundles a full offline model set.
- Multi-monitor setups are structurally supported but less heavily
  live-tested than single-monitor.
- No installer, auto-update, or uninstaller beyond deleting the folder.

## What changed since the last release candidate (V6.8 → V6.9)

Two real defects were found during release QA and fixed in this build:

- `THIRD_PARTY_NOTICES.txt` (EasyOCR/CRAFT-pytorch attribution) is now
  actually included in the ZIP — it existed in source before but never
  made it into the packaged build.
- Both application windows now show the correct branded icon in their
  title bar (previously a generic default; the taskbar/Explorer icon was
  always correct).

See [docs/V6_9_RC_QA.md](https://github.com/danishirfan21/Local-OCR/blob/main/docs/V6_9_RC_QA.md) for the full QA record.
